**프로젝트명:** 소형 IoT 기반 실내 악취 발원지 추적 및 환경 모니터링 시스템  

---

## 1. 목적 (Project Objectives & Analysis)

### 1.1 프로젝트 추진 배경 및 필요성
* **밀폐·공유 공간 내 국소 악취 발생원의 식별 한계:** 다수가 생활하거나 장시간 체류하는 실내 공간(학습실, 공동 주거 공간, 휴게 구역 등)에서는 주기적으로 원인을 알 수 없는 불쾌한 냄새가 발생하여 쾌적성을 저해합니다. 악취는 특정 배출원(환기 사각지대, 특정 집기류 주변, 외부 유입 틈새 등)에서 국소적으로 시작되는 경우가 많으나, 육안으로 확인되지 않아 정확한 발원 지점을 파악하기 어렵습니다.
* **인간 감각의 순응(후각 피로) 및 객관적 지표 부재:** 인간의 후각은 동일한 자극에 지속적으로 노출될 경우 감각 순응(Sensory Adaptation)이 빠르게 일어나 오염 농도의 점진적 증가를 인지하기 어렵습니다. 이로 인해 적절한 환기 시점을 놓치거나 오염원이 방치되는 문제가 발생하므로, 정량화된 수치 데이터를 통한 지속적인 감시 체계가 요구됩니다.
* **소형 분산형 센싱 체계의 필요성:** 대규모 설비용 공조 관제 시스템은 부피와 비용 문제로 실내 미세 구역 단위로 설치하기 불가능합니다. 따라서 오염 의심 구역에 손쉽게 거치 및 부착하여 지점별 공기질 변화를 실시간으로 추적할 수 있는 경량화된 분산 IoT 센싱 솔루션이 필요합니다.

### 1.2 프로젝트 최종 목표
본 프로젝트는 실내 미세 구역별 실시간 오염도 측정과 국소 발원지 추적을 통한 선제적 환경 개선을 목표로 합니다.
1. **분산 부착형 엣지 노드를 통한 발원 지점 모니터링:** 소형 엣지 제어기를 오염 의심 지점에 분산 배치하여 24시간 실시간으로 유해가스 농도 및 환경 데이터를 수집합니다.
2. **현장 즉시 경보 (Local Reactive Feedback):** 측정값이 사전 설정된 임계치를 초과할 경우, 중앙 서버의 통신 지연과 무관하게 기기 자체의 시청각 장치(LED/부저)를 가동하여 현장 재실자에게 즉각적인 조치(환기, 오염원 제거)를 유도합니다.
3. **시계열 데이터 축적 및 웹 대시보드 시각화:** 수집된 데이터를 백엔드 서버에 적재하고 웹 인터페이스를 통해 지점별·시간대별 농도 추이를 그래프로 표출함으로써, 특정 시간대나 구역에서 발생하는 농도 급증 패턴을 분석하고 발원지를 규명합니다.

### 1.3 기대 효과
* **실내 공기질 관리 효율화:** 감각적 추측이 아닌 데이터 기반으로 오염 지점을 정확히 식별함으로써 불필요한 공조 설비 가동을 줄이고 적시 환기를 유도합니다.
* **생활 환경의 쾌적성 및 집중도 제고:** 학습 및 주거 공간의 유해가스 축적을 사전에 방지하여 두통이나 불쾌감을 줄이고 쾌적한 환경을 유지합니다.
* **하드웨어-소프트웨어 융합 설계 경험 확보:** 임베디드 센서 제어, 네트워크 텔레메트리 전송, 백엔드 데이터 처리, 웹 시각화에 이르는 전주기적 시스템 아키텍처를 구현합니다.

## 2. 작성 범위

### 1단계 : 대상 제어기 선택 및 하드웨어 구성

시스템의 데이터 수집 및 1차 현장 반응을 담당하는 엣지 노드는 협소한 공간에 거치 가능하면서 무선 네트워크 연동과 연산 처리를 동시에 수행할 수 있는 소형 임베디드 플랫폼을 채택합니다.

#### 1) 메인 제어기 (Edge Controller)
* **적용 기기:** Raspberry Pi 기반 단일 보드 컴퓨터(SBC)
* **선정 근거:**
  * 가스 센서의 아날로그 신호를 수신해 노이즈 필터링(이동평균 등) 연산을 수행할 수 있는 연산 처리 능력을 보유합니다.
  * Wi-Fi 통신을 기본 지원하여 별도의 유선 케이블 포설 없이 분산 배치가 용이합니다.
  * 추후 센서 노드 증설 및 경량 이상 탐지 알고리즘 이식이 가능한 확장성을 제공합니다.

#### 2) 입력 센서 구성 (Input Sensors)
| 부품명 | 담당 역할 | 기술적 특징 및 보정 방안 |
| :--- | :--- | :--- |
| **MQ-135** | **실내 복합 유해가스/악취 감지** | 암모니아($\text{NH}_3$), 황화수소($\text{H}_2\text{S}$), 알코올 등 실내 유기성 오염 물질에 반응하여 전기 전도도 변화를 아날로그 전압으로 출력합니다. |
| **DHT-22** | **환경 온습도 측정 및 가스 보정** | 반도체식 가스 센서는 주변 온습도에 따라 저항값 편차(Drift)가 발생하므로, 정확한 농도 환산을 위한 환경 보정 계수 도출에 사용합니다. |
| **MCP3008** | **아날로그-디지털 변환기 (ADC)** | 라즈베리파이의 디지털 GPIO 핀으로 아날로그 전압 출력을 수신하기 위해 10비트 분해능의 SPI 통신 변환기를 적용합니다. |

#### 3) 출력 액추에이터 구성 (Output Actuators)
| 부품명 | 제어 방식 | 동작 시나리오 및 역할 |
| :--- | :--- | :--- |
| **RGB LED** | **GPIO 디지털 출력** | 기기 전면에 실시간 오염 단계를 3색으로 가시화합니다.<br>- 🟢 **정상(Normal):** 기준치 이하, 청정 상태 유지<br>- 🟡 **주의(Caution):** 미세 농도 상승 감지, 지속 모니터링<br>- 🔴 **경고(Warning):** 임계치 초과, 환기 및 발생원 점검 요구 |
| **Active Buzzer** | **GPIO 출력 제어** | 오염도가 위험 임계치를 지속해서 상회할 경우 단속적인 비프음을 출력하여 시각적 확인이 어려운 위치에서도 즉각 상황을 인지하도록 지원합니다. |

#### 4) 제어기 내부 데이터 처리 흐름
1. **샘플링 및 노이즈 필터링:** 1초 간격으로 ADC 채널을 통해 가스 센서의 원시(Raw) 전압값을 취득하고, 온습도 보정 수식을 적용하여 유효 가스 지표로 환산합니다.
2. **로컬 임계치 판정 및 자율 제어:** 산출된 지표를 바탕으로 기기 내부 로직에서 상태(정상/주의/경고)를 판정하고 즉시 LED 색상 제어 및 부저 구동 명령을 수행합니다.
3. **텔레메트리 패킷 생성 및 전송:** 측정 시각, 노드 식별자, 보정된 가스 수치, 온습도 데이터를 JSON 포맷으로 패키징하여 3~5초 주기로 백엔드 REST API 엔드포인트로 전송합니다.
